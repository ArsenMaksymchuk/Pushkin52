# Pushkin 52 — сайт (Кишинёв)

Многоязычный сайт ресторана Grill · Hookah · Bar: Strada Pușkin 52, MD-2005, Chișinău, тел. +373 675 81 666, Instagram @pushkin.52.

- Один файл `index.html` (фото встроены), без сборки
- Языки: RO (по умолчанию), RU, UK, EN, PL — переключатель в шапке
- Меню: «Фирменное» (7 позиций) + полная винная карта (Prosecco, красное, розовое, белое, игристое, вино бокалом) с ценами в MDL
- Кнопка «Заказать доставку» (в шапке героя, в плавающей кнопке и в футере): форма → сообщение в WhatsApp +373 675 81 666 или звонок
- Режим работы 10:00–00:00 ежедневно + статус «открыто/закрыто» по времени Кишинёва
- 3D (three.js r128): реалистичный кальян с дымом, доска со стейком, коктейль; при наведении на кнопки вылетают 3D-предметы
- Галерея из 13 фото: наклон, зум, подсветка и подпись при наведении
- Мини-карта (схематичная SVG) + Google Maps
- Логотип (SVG) — нарисован мной по стилю Instagram, замените на настоящий
- Цвета из Instagram: тёмно-зелёный, чёрный, крафт-бежевый, красный, янтарный

## Как менять
Тексты — объект `K` (румынский — в самом HTML, `data-i`). Меню — `SP`, `WN`, `WG`. Фото — массив `PH`.

## Проверить
Работает ли WhatsApp на номере, реальный логотип, названия блюд (взяты из подписей Google и отзывов), права на фото (Google/Instagram).
